# Comparative Study of AGCRN and Graph WaveNet Architectures Using the SUNT Dataset

## Overview

This repository presents a comparative study between the Adaptive Graph Convolutional Recurrent Network (AGCRN) and Graph WaveNet (GWN) architectures for spatiotemporal forecasting tasks using data from the SUNT dataset (https://github.com/LabIA-UFBA/SUNT). The project investigates the predictive performance, computational behavior, and modeling characteristics of both graph-based deep learning approaches under a unified experimental pipeline.

## Repository Content

The repository includes data preprocessing procedures, temporal partitioning strategies, graph construction methods, model implementations, training configurations, hyperparameter settings, evaluation metrics, and reproducible experiments designed to ensure methodological consistency across architectures.

## Comparative Analysis

The comparative analysis focuses on:
- Forecasting accuracy  
- Convergence behavior  
- Robustness  
- Computational efficiency  


## Research Objective

This work aims to support reproducible research in Spatio-Temporal Graph Neural Networks (STGNNs) and provide a transparent experimental framework for benchmarking graph-based forecasting models using real-world transportation data from the SUNT dataset.

## Keywords

Spatio-Temporal Forecasting, Graph Neural Networks, AGCRN, Graph WaveNet, Deep Learning, Transportation Data, Time Series Prediction, Benchmarking.
